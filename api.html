Une clé, un en-tête.
Votre clé API est votre identifiant personnel : elle autorise vos applications à interroger nos données et décompte vos tokens API. Créez-la depuis votre compte, puis envoyez-la dans l’en-tête Authorization de chaque requête.

# En-tête à ajouter à chaque requête

Des tokens API, sans expiration.
1 requête = 1 token API en moyenne. 100 tokens API sont offerts à l’inscription, 5 000 par an avec le Premium annuel et 15 000 avec l’accès à vie. Au-delà, rechargez par packs ou contactez-nous pour de gros volumes.
