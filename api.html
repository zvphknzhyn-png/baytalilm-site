Prêt en trois lignes

Remplace TA_CLE par ta clé gratuite. Change lang pour avoir la réponse en arabe, anglais ou espagnol.

curl "https://api.baytalilm.info/api/hadith/random?lang=fr&apikey=TA_CLE"
const r = await fetch("https://api.baytalilm.info/api/hadith/random?lang=fr&apikey=" + TA_CLE);
const { data } = await r.json();
console.log(data);
import requests
r = requests.get("https://api.baytalilm.info/api/hadith/random", params={"lang": "fr", "apikey": TA_CLE})
print(r.json()["data"])
