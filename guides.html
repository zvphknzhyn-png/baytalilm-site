Guides

Guides pas à pas

Tout ce qu’il faut pour bien démarrer, étape par étape.

Installer le bot Discord
  1. Clique sur Ajouter à mon serveur.
  2. Choisis ton serveur dans la liste (il faut la permission « Gérer le serveur »).
  3. Valide les permissions proposées par Discord : elles servent à publier, à jouer la radio et à répondre aux commandes.
  4. Dans ton serveur, tape /commandes pour voir toutes les commandes.
Lancer la radio sur ton serveur (💎 Premium)
  1. La radio 24h/24 est un avantage Premium : active d’abord ton abonnement (essai gratuit de 7 jours).
  2. Rejoins un salon vocal.
  3. Tape /radio start : la radio démarre.
  4. Tape /radio switch pour choisir un récitateur (menu A à Z, recherche 🔎 et favoris ⭐).
  5. /radio relance si le son bloque, /radio stop pour arrêter.
Activer Premium
  1. Ouvre la page Abonnements et choisis une offre.
  2. Dans le champ « Ton pseudo Discord ou Telegram », écris exactement ton pseudo.
  3. Paie par carte, Apple Pay ou Google Pay sur la page sécurisée Stripe.
  4. Une minute après, tape /premium dans le bot pour vérifier.
Utiliser le bot Telegram
  1. Abonne-toi (page Abonnements ou /premium en Stars).
  2. Ouvre @Baytalilmapp et tape /start.
  3. Tape /commandes pour la liste complète.
  4. Pour un groupe : ajoute le bot à un groupe dont tu es administrateur.
Ajouter les horaires à ton téléphone
  1. Ouvre Horaires et choisis ta ville (ou la localisation).
  2. Touche « Calendrier 30 jours » : un fichier .ics se télécharge.
  3. Ouvre-le : ton agenda ajoute chaque prière avec une alerte 10 minutes avant.
  4. Pour une icône sur l’écran d’accueil : touche une prière puis « Widget ».
Permissions et données
  1. Le bot ne lit que les commandes et les boutons qui lui sont destinés.
  2. Le site ne demande jamais l’accès à ton compte Discord, Telegram ou X.
  3. Le paiement est traité par Stripe : nous ne voyons jamais ton numéro de carte.
  4. Détails : politique de confidentialité.
