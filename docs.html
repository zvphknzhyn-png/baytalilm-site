API Bayt Al-Ilm

Une API REST en JSON pour le Coran, les hadiths, le tafsîr, la prière, la qibla, le calendrier hégirien, les douas, les 99 noms, la zakât et la lune. URL de base : https://api.baytalilm.info.

Clé API gratuite

La clé est gratuite. Ajoute-la à chaque requête avec ?apikey=TA_CLE. Sans clé, les limites sont plus basses.

Obtenir ma clé gratuite

Langues : le paramètre lang

lang=fr, ar, en ou es choisit la langue de la réponse. Quand un texte n’existe pas encore dans la langue demandée, la réponse le signale et donne la langue de repli.

Format des réponses

{
  "success": true,
  "service": "quran",
  "lang": "fr",
  "data": { … },
  "attribution": "source et version du texte",
  "timestamp": "2026-11-25T00:00:00Z"
}

CodeSens
